# PROJECT_ENABLEMENT_PROTOCOL.md

## Propósito

Definir el protocolo para habilitar proyectos objetivo en el orquestador local.

## Modos de habilitación

- Local primero.
- Replit primero.
- Proyecto existente.
- Proyecto nuevo.
- GitHub.
- Carpeta importada.

## Resultado esperado

Ningún proyecto objetivo debe quedar habilitado sin registro, perfil, mapa documental, mapa de código, alertas iniciales y estado de sincronización.
