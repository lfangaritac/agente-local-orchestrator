# CONTEXT_SYNC_PROTOCOL.md

## Propósito

Definir cómo se mantiene actualizado el contexto de cada proyecto objetivo.

## Eventos de sincronización

- habilitación inicial;
- cambios de rama;
- pull o actualización remota;
- commits relevantes;
- handoffs;
- pruebas;
- errores corregidos;
- escalamiento premium;
- handoff a Replit;
- cierre de tareas importantes.
