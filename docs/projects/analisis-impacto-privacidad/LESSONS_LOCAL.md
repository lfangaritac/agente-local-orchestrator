# LESSONS_LOCAL - analisis-impacto-privacidad

## Lecciones iniciales

- El proyecto tiene documentacion tecnica extensa; antes de cambios funcionales revisar `replit.md` y `docs/DOCUMENTACION_TECNICA.md`.
- El CSS de Tailwind no se genera dinamicamente; los ajustes visuales pueden requerir editar `client/src/index.css`.
- La deuda TypeScript debe abordarse por familias, no por casts masivos.
- Cualquier trabajo que toque DB, OpenAI Assistants o vector stores requiere gate de secrets y autorizacion.
