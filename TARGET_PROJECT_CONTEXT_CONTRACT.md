# TARGET_PROJECT_CONTEXT_CONTRACT.md

## Propósito

Definir el contrato de contexto para proyectos objetivo habilitados en el orquestador local.

Este documento establece cómo `C:\Agente` debe indagar, descubrir, registrar, indexar, contrastar, referenciar y sincronizar el contexto documental, técnico y embebido de cada proyecto objetivo.

## Principio central

`C:\Agente` es el orquestador local maestro. No reemplaza el contexto propio de cada proyecto objetivo.

Cada proyecto objetivo conserva su documentación viva, su código, sus decisiones y sus registros. El orquestador debe indagar ese contexto, construir índices consultables y mantener sincronización continua.

## Alcance pendiente de desarrollo

- Contexto transversal del orquestador.
- Contexto propio del proyecto objetivo.
- Acceso nivel 3 de Continue al código.
- Acceso nivel 3 de OpenCode al código.
- Contrastación documentación-código.
- Contexto embebido en comentarios y archivos.
- Índices centralizados con trazabilidad a fuentes.
- Alertas críticas.
- Lecciones aprendidas transversales.
- Mini-orquestación bidireccional Continue ↔ OpenCode.
- Automatización transparente para el usuario.
